## Formatting

**Typography:**
- Body text: Calibri 11pt, 1.15 line spacing
- Heading 1: Calibri 14pt bold
- Heading 2: Calibri 12pt bold
- Heading 3: Calibri 11pt bold italic

**Tables:**
- Font: Calibri 9-10pt
- Header row: bold, dark blue background (#1F4E79), white text
- Alternating row shading: light gray (#F2F2F2) on even rows
- Borders: thin (0.5pt) gray (#D9D9D9) horizontal lines; no vertical borders
- Column widths: auto-fit to content; first column (label) no wider than 25% of table width
- Table caption: bold, above table, numbered by section (e.g., "Table 2.1: MoA Classes in IgA Nephropathy")

**Cover page:**
- Title: Calibri 20pt bold
- Subtitle (focus compound, if any): Calibri 14pt
- Date: YYYY-MM-DD format
- Attribution: "Generated with vera-clinical-indication-researching"
- Confidentiality: "For internal use only" (or omit if user specifies otherwise)

**References:**
- Numbered citation style: [1], [2], etc. in text
- Reference list at end: Author(s). Title. Journal Year;Volume:Pages. DOI or URL.
- All URLs cited in research steps must appear in references
- ClinicalTrials.gov entries: list as NCT number, trial title, sponsor, status

**Length guidance:**
- Standard depth: ~15-25 pages
- Deep mode: ~25-40 pages
- Executive summary (if included): 1 page maximum
- Development Implications section: 2-3 pages
